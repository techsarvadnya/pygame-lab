# 🎮 Pygame Lab

A hands-on journey into Python game development.

## 🚀 About This Project

Pygame Lab is my learning space for exploring game development
with Python and Pygame.

My goal is to understand game logic, experiment with ideas,
debug problems, and gradually build original games—not just
copy code.

## 🛠️ Tech Stack

- Python 3.13.16
- Pygame 2.6.1
- Visual Studio Code
- Git and GitHub

## 📚 Learning Roadmap

- [x] Set up Python and Pygame
- [x] Explore screen coordinates and pixels
- [x] Draw basic shapes
- [ ] Understand the game loop and event handling
- [ ] Write programs independently
- [ ] Learn keyboard controls and collisions
- [ ] Build small original games

## 📈 Progress

I am currently learning the fundamentals of Pygame,
including screen coordinates, shape drawing, and program logic.

As I learn, I will add code examples, experiments, and
projects to this repository.
